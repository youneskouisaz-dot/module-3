# LinkedList Assignment

This project implements a singly linked list in Python.

The linked list is built using nodes, where each node stores data and a reference to the next node in the list.

## Features

The implementation includes:

* Add an element to the beginning of the list
* Add an element to the end of the list
* Remove the first element
* Remove the last element
* View the first element
* View the last element
* Convert the linked list into a Python list

## Files

* `linked_list.py` — contains the `Node` and `LinkedList` classes
* `test_linked_list.py` — contains tests for the linked list implementation
* `README.md` — project documentation

## Testing

The project uses `pytest` to test the linked list.

Run the tests with:

```bash
pytest
```

The goal is for all tests to pass successfully.

## Extension

The optional extension is to implement a doubly linked list that supports traversal in both forward and reverse directions.
